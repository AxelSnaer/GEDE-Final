# Final project - Godot Raymarching Extension

In order to build this project, you will need to have `scons` and a functional C++ compiler (MinGW recommended if on Windows) installed.
Make sure to pull all submodules using this command: `git submodule update --init --recursive`

Once all that is done, build the project by running this command: `scons`.

Once the project is built. You can run the Godot project under the `demo/` directory
